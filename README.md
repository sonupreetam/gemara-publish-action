# gemara-publish-action

GitHub Action for Gemara OCI publish and trust orchestration. Wraps
[grcli](https://github.com/gemaraproj/grcli) — the standalone CLI for the
GRC artifact registry at [grc.store](https://grc.store) — to validate, sign,
and publish Gemara bundles from GitHub Actions.

| Phase | What it does |
|--------|----------------|
| **1 — Validate** | Optional `grcli validate` (`cue vet` against authoritative Gemara CUE schemas). |
| **2 — Publish** | `grcli publish`: assemble dependencies, pack into signed OCI bundle with SLSA-shaped provenance, push to hub-managed registry via trusted publishing. |
| **3 — Promote (optional)** | ORAS copy to a **destination** registry with `trust_mode`. |
| **4 — Trust (destination)** | Optional cosign sign/verify on the **destination** digest when promotion is enabled. |

**Outputs:** `digest` / `source_digest` are **normalized** to `sha256:<64 lowercase hex>` for stable downstream use.

**Who owns the contract:** [grcli](https://github.com/gemaraproj/grcli) and
[go-gemara](https://github.com/gemaraproj/go-gemara) own bundle media types,
manifest shape, signing, and Pack/Assemble. This action does not.

### Boundaries (what is *not* in this action)

- **SLSA provenance** is generated by grcli during publish — this action does not add its own.
- **SBOM** and **vulnerability** attestations are **out of scope** — add them in **separate job steps** after publish.
- **Branch / environment / approval** gates are **not** enforced inside the composite. Use **caller workflow** `if:` and GitHub **Environments**.
- Composites only receive **string** inputs. Boolean-like flags are the literal strings **`"true"`** and **`"false"`**.

### Authentication

**No GitHub secret is needed for publishing.** `grcli publish` uses the workflow's
GitHub OIDC token as its credential (trusted publishing). The only requirement is
`permissions: id-token: write` on the job and a one-time trusted-publisher binding
for your repository on the hub.

Do **not** add `GRCLI_TOKEN`, a PAT, or any `secrets.*` reference for the publish step.

### Caller patterns

Reusable **workflows** can set `concurrency:`, `environment:`, and `if: github.ref_protected` on a **job**. A **composite** cannot — so apply these on the **job** that invokes this action.

## Key inputs

| Input | Description |
|-------|-------------|
| `file` | Root Gemara artifact YAML (Policy, Catalog, or Guidance). **Required.** |
| `license` | SPDX license expression (e.g. `Apache-2.0`). **Required.** |
| `validate` | Run `grcli validate` before publish (`"true"` / `"false"`). |
| `gemara_spec_dir` | Path to a local Gemara spec checkout for validation (optional). |
| `working_directory` | Working directory relative to repo root for resolving `file`. |
| `grcli_version` | grcli release tag to install (default `v0.1.0`). Pin for reproducibility. |
| `grcli_url` | Hub base URL (default `https://hub.grc.store`). |
| `repository` | Override OCI push destination (usually derived from bundle metadata). |
| `no_sign` | Skip signing (`"true"` / `"false"`). |
| `dry_run` | Write OCI layout locally instead of pushing (`"true"` / `"false"`). |
| `dry_run_output` | Output directory for dry-run mode (default `grcli-out`). |
| `oras_version` | ORAS CLI version to install (default `1.2.0`). |
| `promote_to_destination` | Enable promotion to `destination_*`. |
| `destination_registry`, `destination_repository`, `destination_tag` | Destination registry coordinates. |
| `destination_username`, `destination_password` | Destination registry credentials. |
| `trust_mode` | `copy-only`, `copy-referrers`, or `resign`. |
| `sign_destination` | Keyless-sign destination digest (`"true"` / `"false"`). |
| `verify_destination` | Destination signature verification control. |
| `cosign_version` | Cosign release version for promotion trust handling. |
| `cosign_certificate_oidc_issuer` | OIDC issuer for cosign verify on promoted artifacts. |
| `allowed_identity_regex` | Optional cosign identity regex override. |

## Outputs

| Output | Description |
|--------|-------------|
| `digest` / `source_digest` | Source manifest digest, `sha256:` + 64 hex (lowercase). |
| `source_ref` | Source reference with digest. |
| `destination_digest` | Destination digest after promotion. |
| `destination_ref` | Destination image reference with digest. |
| `verified_destination` | `true` if destination verify passed. |
| `trust_mode` | Effective trust mode used. |

## Promotion and trust

- Set `promote_to_destination: "true"` and **`destination_*`** inputs to copy the published
  artifact to a second registry (e.g. hub registry -> Quay).
- Default trust path: `trust_mode: resign`, `sign_destination: "true"`, `verify_destination: "true"`.
- Optional compatibility modes: `copy-only` (payload only), `copy-referrers` (recursive copy).

## Minimal caller example

```yaml
permissions:
  contents: read
  id-token: write   # OIDC token for hub auth + keyless signing

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - id: publish
        uses: gemaraproj/gemara-publish-action@<pinned-sha>
        with:
          file: governance/policies/my-policy.yaml
          license: Apache-2.0
```

### With promotion

```yaml
permissions:
  contents: read
  id-token: write
  packages: write

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - id: publish
        uses: gemaraproj/gemara-publish-action@<pinned-sha>
        with:
          file: governance/policies/my-policy.yaml
          license: Apache-2.0
          repository: myorg/my-policies
          promote_to_destination: "true"
          destination_registry: quay.io
          destination_repository: myorg/my-policies
          destination_username: ${{ secrets.QUAY_ROBOT_USERNAME }}
          destination_password: ${{ secrets.QUAY_ROBOT_TOKEN }}
```

## Migration from v1 (embedded grc CLI)

The previous version of this action used an embedded Go CLI (`cmd/grc/`) that
built from source on every run. Key changes:

| Before (v1) | After (v2) |
|------------|-----------|
| `registry` + `username` + `password` for source | Hub-based trusted publishing (OIDC, no secrets) |
| `tag` input | Derived from bundle metadata by grcli |
| `bundle_version` input | Managed by grcli / go-gemara SDK |
| `sign_source` / `verify_source` | grcli signs in-process by default |
| Cosign required for source signing | Cosign only needed for promotion |
| Go toolchain installed at runtime | Pre-built grcli binary |
| `validate` used `cue vet` (manual setup) | `grcli validate` (cue built-in) |
| No `license` input | `license` is **required** |
